# Projeto de recomendação por meio de imagens

Este projeto implementa um sistema de recomendação baseado em imagens de roupas, utilizando Deep Learning com MobileNetV2. Ao fornecer uma imagem (da internet ou local), o sistema retorna os produtos visualmente mais similares com base em embeddings extraídos da imagem.
